# Chabod redesign — design reference

Put this folder at the repo root as `/design-reference/`. These files are **reference only**. Don't import them into the app.

- `CLAUDE_CODE_PROMPT.md`: the prompt to give Claude Code.
- `Chabod Prototype.dc.html`: clickable mobile prototype of every screen, member and admin, in dark and light.
- `Chabod Design System.dc.html`: tokens, type, spacing and components.
- `Chabod Wide Layouts.dc.html`: tablet split view and desktop rail.
- `Chabod Phase 1 (directions).dc.html`: the three explored directions (1a was chosen).
- `support.js`, `_ds/`: runtime and styles the `.dc.html` files need to open.

To view them, serve the folder locally (for example `npx serve design-reference`) and open the `.dc.html` files. Opening them straight from disk may block the scripts.
